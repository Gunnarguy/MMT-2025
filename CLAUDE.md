# MMT-2025 - the Michigan '26 field guide and Town Scout matrix, React 19 + Vite 7, static on GitHub Pages

## Verify

The app is in `trip-planner/`. After any change:

    cd trip-planner && npx --no-install eslint <changed files> && npm run build    # build 1.16 s median, n=17, max 3.5 s (brief section 8)

Do not report done until this exits 0 and you have read the output.
A change is live only when all three of these hold, in order:

    git push origin main                                                                          # deploy.yml runs on push, about 33 s
    gh run watch "$(gh run list --limit 1 --json databaseId --jq '.[0].databaseId')" --exit-status --interval 10
    curl -s https://gunnarguy.github.io/MMT-2025/ | grep -oE 'assets/index-[A-Za-z0-9_-]+\.js'  # the hash must differ from before

Say "live" only after the asset hash changed. "Is this on the GitHub page" was asked five times against this same chain.
To look at it locally: `.claude/launch.json` target `michigan-26` serves `trip-planner` on port 5174.

## Never

- Never silently overwrite the planning document. Each day keeps the author's verbatim text in its `momSaid` block and every correction is an explicit flag with a source link (`trip-planner/README.md`; nine such blocks in `src/data/trip.js`). This is the founding rule of the 2026-08 rebuild.
- Never add a backend, account, login, sync or database. The previous version had Supabase, realtime sync and an email wall and nobody used it; the 2026-08 rebuild deleted all of it (`trip-planner/README.md`). The only persisted state is `localStorage` checkboxes.
- Never put a figure in `src/data/relocation.js` without a source and a date. Wrong prices on 2026-08-29 triggered "how accurate and certain are you" and the CARTO/BigQuery rebuild; the file header records 55 figures confirmed and 26 corrected to ranges (brief section 12.5).
- Never echo a credential into a Bash command, a file or a message. The CARTO token was pasted into chat on 2026-08-29, echoed into seven Bash commands, and now sits in a transcript kept for 365 days. MCP headers belong in `~/.claude.json` project scope only (brief section 15.4).
- Never present comparisons as cards. One sortable matrix with the home-baseline row pinned; cards only for a single town's deep dive. The card layout cost a full rebuild on 2026-09-06 (brief section 10.4).
